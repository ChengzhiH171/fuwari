## 修复右栏滚动错位（第三次迭代）

**现象**：主页滚动时右栏（天气/日期）比左栏和正文"晚贴顶"，视觉错位。

**根因**：`Layout.astro` 全局样式中，主页 hero 模式（`.enable-banner.is-home`）把 `#main-grid` 整体 `translate-y-[30vh]`，并给左栏 `#sidebar-sticky` 设了负 top 补偿 `top-[calc(1rem_-_var(--banner-height-extend))]`。新加的右栏没有该补偿，吸附点整体低 30vh。

**修复**：在 Layout.astro 同一全局样式块加 `.enable-banner.is-home #sidebar-right-sticky { @apply top-[calc(1rem_-_var(--banner-height-extend))] }`。

**调试要点**：排查耗时长的原因是几个干扰项——OverlayScrollbars 把 html 本身变成滚动容器（`<html data-overlayscrollbars-viewport>`，tagName 是 HTML！）、onload-animation 的 fill-mode:forwards 永久保持 transform:translateY(0)、agent-browser scroll 是平滑滚动导致测量时机不稳。定位手段：插入干净的探针 sticky 元素到不同层级做对照（html 直系正常、main-grid 内失效→锁定局部原因），再审计祖先链 computed style 发现 main-grid 的 translateY(200px)。

**验证**：主页 scrollY=700 三栏顶全对齐（174/174/174），滚过 banner 后右栏贴视口 16px；文章页 scrollY=500 右栏 16px 正常。

### 踩坑
- Svelte 5 runes 模式下 class 指令不能用 `class:text-[var(--primary)]`（类名含特殊字符），改用 class 字符串拼接。
- 重写组件时漏掉 `toggleMute` 函数导致 astro-island 水合报错 "toggleMute is not defined"，整个 widget 空白——构建不报错，必须浏览器实测。
- 验证方式：pnpm build + astro preview + agent-browser 截图/eval 检查音频 readyState、播放状态、日历翻月。

### 其他
- 音乐默认用 SoundHelix 示例 mp3 占位，用户需在 `musicConfig.tracks` 里换成自己的音频/封面。
- 临时装了全局 agent-browser（npm -g）用于浏览器验证。
